# 视频推荐系统项目 - Video Recommendation System

## 项目简介
本项目是一个短视频推荐系统的全链路实现，涵盖了从数据处理、多路召回、精排模型到多样性重排的完整流程。系统旨在处理用户行为数据，提供个性化推荐服务。

## 核心架构
系统采用推荐领域常用的三阶段架构：
1. **召回层 (Recall)**: 从海量视频库中快速筛选出候选视频。
2. **精排层 (Ranking)**: 使用深度学习模型对候选集进行打分预估。
3. **重排层 (Reranking)**: 兼顾推荐结果的多样性、新鲜度及相关策略。

```
┌─────────────┐
│   用户请求   │
└──────┬──────┘
       │
┌──────▼──────────────────────────────────────┐
│            召回层 (Recall)                    │
│  ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐│

└──────────────────┬──────────────────────────┘

               └───────┘
```

## 数据集说明
本项目使用 **KuaiRand-1K** 真实短视频数据集进行实验：
- **用户规模**: 1,000 名活跃用户。
- **视频库**: 包含视频元数据及特征。
- **交互日志**: 包含 `log_standard`（标准日志）和 `log_random`（随机曝光日志）。
- **离线评估**: 使用随机曝光日志进行评估，以减少推荐系统中的偏差。

## 核心模块实现

### 1. 7 路多路召回策略
系统集成了以下召回通道：
- **ItemCF**: 基于物品协同过滤，捕捉用户历史偏好的相似内容。
- **UserCF**: 基于用户协同过滤，挖掘志趣相投用户的潜在兴趣。
- **DeepWalk**: 图向量召回，利用交互构建图关系捕捉深层关联。
- **TwoTower**: 双塔向量召回，支持向量检索。
- **HotRecall**: 热门内容召回，作为系统保底策略。
- **NewItemRecall**: 新内容召回，给予新视频曝光流量。
- **FollowRecall**: 关注召回，推荐用户关注作者的动态。

### 2. DIN 精排模型 (Deep Interest Network)
- **特征工程**: 融合了用户特征（活跃度、等级等）、视频特征（类目、作者等）及上下文特征。
- **注意力机制**: 引入 Local Activation Unit，计算用户历史行为与当前候选视频的相关性，捕捉用户的兴趣点。

### 3. 多样性重排
- **MMR 算法**: 在相关性与多样性之间取得平衡。
- **新鲜度优化**: 引入时间衰减因子，提升新内容的曝光比例。
- **规则过滤**: 实现了作者去重、类目打散等策略。

## 快速开始

### 1. 环境准备
```bash
pip install torch pandas numpy pyyaml scikit-learn
```

### 2. 数据配置
在 `config/config.yaml` 中配置数据集的本地路径：
```yaml
data:
  kuairand_path: "E:/data/KuaiRand-1K/data"
```

### 3. 运行链路

**第一步：训练 7 路召回模型**
```bash
python scripts/train_recall.py
```

**第二步：训练精排模型**
```bash
python scripts/train_din.py
```

**第三步：启动推荐服务演示**
```bash
python src/serving/recommendation_service.py
```

## 性能优化
- **并行计算**: 采用多进程加速召回计算。
- **向量化检索**: 支持离线预计算向量，提高检索速度。
- **复杂度重构**: 优化重排层逻辑，降低系统延迟。
